Two Modes: Single-Day vs. Multi-Day

Single-Day Mode

report_writing_node()

  • Takes one day's findings from PipelineState
  • Serialises all agent findings as JSON
  • Single LLM call with system prompt
  • Output: incident_report_YYYY-MM-DD.md/.pdf

Multi-Day Mode

write_combined_report()

  • Receives all per-day results as a list
  • Deduplicates before LLM call:
    • IOCs by (type, value) tuple
    • MITRE techniques by attack_id
    • Threat groups by group_id (top 10)
  • Per-day sections with ──── separators
  • Output: combined_incident_report.md/.pdf

Both modes use the same system prompt, same model (gpt-4o-mini), and same temperature=0.1

8 Mandatory Report Sections

1. Title / Cover Page
Incident header, date range, case ID
2. Table of Contents
LLM-generated to match actual sections
3. Executive Summary
C-suite audience: root cause, business impact, recommendations
4. Detailed Findings
Per attack phase with MITRE ATT&CK mapping:
Initial Access · Lateral Movement · Exfiltration · Payload
5. Conclusion & Recommendations
Prioritised: High / Medium / Low
6. Appendix — Timeline
Chronological reconstruction across all days
7. Appendix — Technical Details
Packet traces, IOC details, 5-tuples
8. Evidence Gaps
What the pipeline could NOT determine — scope limits, missing data

+ Optional 9th section: Evidence Provenance Appendix (auto-appended if --track-provenance enabled)

Anti-Hallucination: 4 Rules + Low Temperature

Rule 1: Evidence References Required

"Every significant claim must include supporting evidence references."

Rule 2: Concrete References Preferred

"Prefer concrete references: 5-tuples, host/user identifiers, timestamps, log sources."

Rule 3: Insufficient Evidence Fallback

"If evidence is missing, write 'Insufficient evidence' rather than guessing."

Explicit escape hatch — the LLM doesn't need to fabricate to fill gaps.

Rule 4: Fabrication Blacklist

"Never fabricate packet IDs, hashes, users, hosts, ATT&CK IDs, or timestamps."

+ Temperature: 0.1

Near-deterministic output. Maximises factual consistency over prose fluency.

Key Challenges

Context Window Pressure

9-day combined report: all agent findings, IOCs, MITRE data across 9 days must fit in context. 16K output token budget constrains report length.

Table Formatting Compliance

LLMs naturally produce multi-line table cells. ReportLab cannot handle this. System prompt includes explicit WRONG/RIGHT examples — but enforcement is best-effort.

Cross-Day Attribution

With 9 days of similar data, the LLM may attribute an IP or timestamp to the wrong day. Per-day sections with visual separators mitigate but don't eliminate this.

No Post-Generation Validation

Unlike the exfiltration agent's grounding check, the report writer has no automated fact-checking. Mitigation: low temperature + strict prompting.

Known limitation — a future improvement area.
